# بيني وبينك — تنفيذ الأساس الخادمي

الترحيل المرفق يبني جداول خاصة منفصلة للملكية والمحادثات والرسائل وحالات القراءة والمتابعة والطلبات والحدود. مفتاح التفعيل مغلق افتراضياً، والمالك الوحيد النشط يُستخرج من السجل الموثوق. لا ينفذ أي تغيير على بيانات الطلاب الأكاديمية.

## بوابات الإطلاق المتبقية
- تطبيق الترحيل وفق مسار النشر المعتمد بعد تحقق النسخة الاحتياطية.
- اختبار حسابين منفصلين وصلاحية المالك وغير المالك، واختبار التزامن وإخفاء الهوية عبر RPC وREST وGraphQL.
- تنفيذ الواجهة وربط الإشعارات والعدادات وآلية تشغيل الطلبات الخاصة بالخصوصية.
- مراجعة سياسة الاحتفاظ والتعامل مع حالات الأذى؛ لا يُشغّل حذف تلقائي قبل ذلك.
- لا تغير enabled إلى true حتى نجاح اختبارات القبول والتأكد من نشر الواجهة.

## إيقاف آمن
`update by_private.settings set enabled=false where singleton;` (صلاحية تشغيل قاعدة البيانات فقط). لا تحذف الرسائل لإيقاف الميزة.
