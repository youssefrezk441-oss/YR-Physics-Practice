# بيني وبينك — الحالة الفنية للإصدار الأول

تمت إضافة ترحيل خاص وإطار واجهة عربي RTL ومسار مشترك للمدرس والطالب، مع مدخل في الشاشة الرئيسية والقائمة، وعدادات وإشعارات داخلية مبنية على استطلاع بيانات القراءة كل 45 ثانية. لا يوجد إرسال خارجي. الواجهة لا تعرض أي مدخل إذا لم يرجع الخادم enabled=true. لا يتم حفظ نصوص الرسائل في التخزين المحلي.

## بوابات الإطلاق
- الترحيل يظل مغلقًا افتراضيًا. التحقق من النسخة الاحتياطية وتطبيقه وفق مسار الإنتاج الرسمي.
- اختبارات العقود المضافة لا تحل محل اختبار حسابين منفصلين وصلاحية المالك وغير المالك، والتزامن وREST وGraphQL وواجهة المستخدم الفعلية.
- التحقق من نجاح CI ونشر Pages والتحقق من المسارات الفعلية.
- مراجعة سياسة الاحتفاظ والتعامل مع حالات الأذى. يوجد استعلام preview للاحتفاظ؛ لا يوجد حذف مجدول بعد. طلبات الخصوصية لها جدول مستقل؛ رابط سياسة الخصوصية الحالي يوضح قنوات تقديم الطلب، ويجب وضع آلية تشغيل للطلبات قبل التفعيل.
- الاستطلاع للعدادات داخل بطاقة الطالب وصندوق المدرس بدل ربط ملكية المراسلة بإشعارات الإدارة العامة. لا محتوى خاص في التنبيهات.
- لا تغير enabled إلى true حتى نجاح اختبارات القبول والتأكد من نشر الواجهة.

## إيقاف آمن
`update by_private.settings set enabled=false where singleton;` (صلاحية تشغيل قاعدة البيانات فقط). لا تحذف الرسائل لإيقاف الميزة.
